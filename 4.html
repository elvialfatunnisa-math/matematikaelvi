BAB 4: Program Linear

Memahami konsep program linear sebagai metode optimasi untuk memaksimalkan atau meminimalkan suatu fungsi tujuan dengan kendala-kendala tertentu. Menguasai model matematika, sistem pertidaksamaan linear, daerah penyelesaian, dan penentuan nilai optimum.

A. Pengertian dan Hakikat Program Linear

Program linear adalah metode matematis yang digunakan untuk menentukan nilai optimum (maksimum atau minimum) dari suatu fungsi linear (fungsi objektif) dengan memperhatikan berbagai kendala (constraints) yang dinyatakan dalam bentuk pertidaksamaan linear.

Program linear banyak diterapkan dalam berbagai bidang seperti ekonomi, industri, transportasi, dan manajemen untuk pengambilan keputusan yang optimal.

"Program linear adalah teknik optimasi yang digunakan untuk mengalokasikan sumber daya yang terbatas secara optimal untuk mencapai tujuan tertentu."
— Definisi Matematis

Komponen utama program linear:

  • Variabel Keputusan: Variabel yang nilainya ingin ditentukan (biasanya x dan y)
  • Fungsi Objektif: Fungsi yang ingin dioptimalkan (maksimum atau minimum)
  • Fungsi Kendala: Pertidaksamaan linear yang membatasi nilai variabel keputusan
  • Syarat Non-Negatif: Variabel keputusan harus bernilai non-negatif (x ≥ 0, y ≥ 0)

B. Model Matematika Program Linear

Model matematika program linear terdiri dari fungsi objektif dan fungsi kendala:

Bentuk Umum Model Matematika:

Fungsi Objektif:
f(x, y) = ax + by (maksimum atau minimum)

Fungsi Kendala:
a₁x + b₁y ≤ c₁
a₂x + b₂y ≤ c₂
...
aₙx + bₙy ≤ cₙ
x ≥ 0, y ≥ 0

📘 Contoh Soal: Model Matematika

Seorang produsen membuat dua jenis roti: Roti A dan Roti B. Setiap Roti A membutuhkan 200 gram tepung dan 100 gram gula. Setiap Roti B membutuhkan 100 gram tepung dan 150 gram gula. Tersedia 4 kg tepung dan 3 kg gula. Keuntungan Roti A Rp5.000 dan Roti B Rp4.000. Buatlah model matematikanya!

Penyelesaian:

Variabel Keputusan:

x = banyak Roti A yang diproduksi

y = banyak Roti B yang diproduksi

Fungsi Objektif (Keuntungan):

f(x, y) = 5000x + 4000y (maksimum)

Fungsi Kendala:

Tepung: 200x + 100y ≤ 4000 → 2x + y ≤ 40

Gula: 100x + 150y ≤ 3000 → 2x + 3y ≤ 60

Non-negatif: x ≥ 0, y ≥ 0

C. Sistem Pertidaksamaan Linear Dua Variabel

Sistem pertidaksamaan linear dua variabel adalah kumpulan pertidaksamaan linear yang melibatkan dua variabel. Penyelesaiannya merupakan irisan dari semua daerah penyelesaian masing-masing pertidaksamaan.

Langkah Menyelesaikan:

1. Gambar garis lurus dari setiap pertidaksamaan (ubah ≤ atau ≥ menjadi =)

2. Tentukan daerah penyelesaian dengan uji titik

3. Arsir daerah yang memenuhi semua pertidaksamaan

4. Daerah arsiran yang beririsan adalah daerah penyelesaian sistem

📘 Contoh Soal: Sistem Pertidaksamaan

Tentukan daerah penyelesaian dari sistem pertidaksamaan:

x + y ≤ 6

2x + y ≤ 8

x ≥ 0, y ≥ 0

Penyelesaian:

Garis 1: x + y = 6 → titik (6, 0) dan (0, 6)

Garis 2: 2x + y = 8 → titik (4, 0) dan (0, 8)

Titik Potong: x + y = 6 dan 2x + y = 8

→ x = 2, y = 4 → titik (2, 4)

Titik Pojok Daerah Penyelesaian:

(0, 0), (4, 0), (2, 4), (0, 6)

D. Daerah Penyelesaian (Feasible Region)

Daerah penyelesaian atau feasible region adalah himpunan semua titik yang memenuhi semua fungsi kendala. Daerah ini berbentuk poligon (segi banyak) yang dibatasi oleh garis-garis kendala.

Sifat Daerah Penyelesaian

  • • Berbentuk poligon cembung
  • • Memiliki titik-titik pojok (vertex)
  • • Terbatas atau tak terbatas
  • • Semua titik di dalamnya memenuhi kendala

Titik Pojok (Vertex)

  • • Titik perpotongan dua garis kendala
  • • Merupakan kandidat solusi optimum
  • • Nilai optimum selalu terjadi di titik pojok
  • • Dapat ditentukan dengan eliminasi/substitusi

E. Metode Penentuan Nilai Optimum

Ada dua metode utama untuk menentukan nilai optimum fungsi objektif:

1. Metode Uji Titik Pojok

Substitusikan semua titik pojok daerah penyelesaian ke fungsi objektif, lalu bandingkan hasilnya.

Contoh:

Fungsi objektif: f(x, y) = 5000x + 4000y

Titik pojok: (0, 0), (4, 0), (2, 4), (0, 6)

f(0, 0) = 0

f(4, 0) = 20.000

f(2, 4) = 26.000 ← Maksimum

f(0, 6) = 24.000

Jadi, nilai maksimum = 26.000 di titik (2, 4)

2. Metode Garis Selidik

Gambar garis selidik ax + by = k, lalu geser sejajar hingga menyentuh titik terjauh (maksimum) atau terdekat (minimum) dari daerah penyelesaian.

Langkah-langkah:

1. Buat garis selidik awal: ax + by = 0 (melalui origin)

2. Geser garis sejajar ke kanan/atas untuk maksimum

3. Geser garis sejajar ke kiri/bawah untuk minimum

4. Titik terakhir yang disentuh adalah solusi optimum

F. Studi Kasus: Penerapan dalam Kehidupan Nyata

Kasus 1: Optimasi Keuntungan UMKM Kue

Seorang pengusaha kue di koperasi madrasah membuat dua jenis kue: Kue Lapis dan Kue Brownies. Kue Lapis membutuhkan 200 gram tepung dan 100 gram cokelat, sedangkan Brownies membutuhkan 100 gram tepung dan 150 gram cokelat. Tersedia 4 kg tepung dan 3 kg cokelat. Keuntungan per Kue Lapis Rp10.000 dan Brownies Rp8.000. Berapa banyak masing-masing kue yang harus diproduksi agar keuntungan maksimum?

Model Matematika:
Fungsi objektif: f(x, y) = 10.000x + 8.000y (maksimum)
Kendala tepung: 2x + y ≤ 40
Kendala cokelat: 2x + 3y ≤ 60
x ≥ 0, y ≥ 0

Solusi: Titik pojok (0, 20), (15, 10), (20, 0)
f(15, 10) = 10.000(15) + 8.000(10) = Rp230.000 (maksimum)
Jadi, produksi 15 Kue Lapis dan 10 Brownies.

Kasus 2: Minimasi Biaya Transportasi

Sebuah madrasah perlu mengangkut 60 murid dengan dua jenis kendaraan: Angkot (kapasitas 10 orang, biaya Rp50.000) dan Minibus (kapasitas 20 orang, biaya Rp100.000). Berapa banyak masing-masing kendaraan yang harus disewa agar biaya minimum?

Model: f(x, y) = 50.000x + 100.000y (minimum)
Kendala: 10x + 20y ≥ 60 → x + 2y ≥ 6
x ≥ 0, y ≥ 0
Solusi: Minimum di titik (0, 3) → 3 Minibus = Rp300.000

G. Tantangan dan Miskonsepsi Umum

Dalam mempelajari program linear, murid sering mengalami:

  • Kesalahan Membuat Model: Salah menentukan variabel keputusan atau fungsi objektif dari soal cerita.
  • Kesalahan Menggambar Grafik: Salah menentukan daerah penyelesaian pertidaksamaan (arsiran).
  • Lupa Syarat Non-Negatif: Mengabaikan kendala x ≥ 0 dan y ≥ 0.
  • Kesalahan Menentukan Titik Pojok: Salah menghitung titik perpotongan dua garis.
  • Kebingungan Maksimum vs Minimum: Tidak jelas apakah soal meminta nilai maksimum atau minimum.
  • Kesalahan Interpretasi: Salah menyimpulkan jawaban akhir dari nilai optimum yang diperoleh.

I. Perbedaan: Maksimasi vs Minimasi

Aspek Maksimasi (Mencari Nilai Maksimum) Minimasi (Mencari Nilai Minimum)
Tujuan Mencari nilai terbesar (keuntungan, produksi) Mencari nilai terkecil (biaya, waktu)
Jenis Kendala Umumnya ≤ (kurang dari atau sama dengan) Umumnya ≥ (lebih dari atau sama dengan)
Metode Garis Selidik Geser garis ke kanan/atas Geser garis ke kiri/bawah
Contoh Aplikasi Maksimalkan keuntungan, produksi, pendapatan Minimalkan biaya, waktu, jarak
Daerah Penyelesaian Terbatas di bawah Terbatas di atas
