BAB 3: Fungsi Invers

Memahami konsep fungsi invers sebagai kebalikan dari fungsi asal. Menguasai syarat keberadaan invers, langkah menentukan f⁻¹(x), hubungan grafik fungsi dan inversnya, serta aplikasinya dalam pemecahan masalah "membalik" proses.

A. Pengertian dan Hakikat Fungsi Invers

Fungsi invers adalah fungsi kebalikan dari fungsi asalnya. Jika fungsi f memetakan x ke y, maka fungsi invers f⁻¹ akan memetakan y kembali ke x. Dengan kata lain, fungsi invers "membalik" arah pemetaan dari fungsi asal.

Secara formal, jika f: A → B adalah suatu fungsi, maka inversnya f⁻¹: B → A didefinisikan sedemikian sehingga:

f(x) = y ⇔ f⁻¹(y) = x
Dibaca: "f invers dari y sama dengan x"

"Fungsi invers adalah fungsi yang diperoleh dengan membalik hubungan antara domain dan range dari fungsi asalnya, sehingga output menjadi input dan sebaliknya."
— Definisi Matematis

Analogi sederhana: Jika fungsi f adalah proses "memasak nasi dari beras", maka fungsi invers f⁻¹ adalah proses "menemukan jumlah beras awal dari nasi yang sudah dimasak".

B. Syarat Fungsi Memiliki Invers

Tidak semua fungsi memiliki invers. Suatu fungsi hanya memiliki invers jika memenuhi syarat berikut:

1. Fungsi Harus Bijektif

Fungsi harus bersifat satu-satu (injektif) dan surjektif (pada). Artinya, setiap anggota domain dipetakan ke anggota kodomain yang berbeda, dan semua anggota kodomain terpasangkan.

2. Uji Garis Horizontal

Setiap garis horizontal harus memotong grafik fungsi paling banyak di satu titik. Jika ada garis horizontal yang memotong lebih dari satu titik, fungsi tidak memiliki invers.

⚠️ Contoh Fungsi yang TIDAK Memiliki Invers:

f(x) = x² (untuk domain semua bilangan real)

Alasan: f(2) = 4 dan f(-2) = 4. Dua input berbeda menghasilkan output yang sama, sehingga fungsi tidak satu-satu. Garis horizontal y = 4 memotong grafik di dua titik.

C. Langkah Menentukan Fungsi Invers

Berikut langkah-langkah sistematis untuk menentukan fungsi invers:

Langkah 1: Misalkan y = f(x)

Langkah 2: Selesaikan persamaan untuk menyatakan x dalam bentuk y

Langkah 3: Ganti x dengan f⁻¹(x) dan y dengan x

📘 Contoh Soal:

Tentukan fungsi invers dari f(x) = 2x + 3!

Penyelesaian:

Langkah 1: Misalkan y = 2x + 3

Langkah 2: Selesaikan untuk x

y = 2x + 3

y - 3 = 2x

x = (y - 3) / 2

Langkah 3: Ganti x dengan f⁻¹(x) dan y dengan x

f⁻¹(x) = (x - 3) / 2

Jadi, f⁻¹(x) = (x - 3) / 2 ✓

D. Contoh Soal Lanjutan

Contoh 1: Fungsi Pecahan

Tentukan invers dari f(x) = (3x - 1) / (x + 2)!

y = (3x - 1) / (x + 2)

y(x + 2) = 3x - 1

xy + 2y = 3x - 1

xy - 3x = -2y - 1

x(y - 3) = -2y - 1

x = (-2y - 1) / (y - 3)

f⁻¹(x) = (-2x - 1) / (x - 3) = (2x + 1) / (3 - x) ✓

Contoh 2: Fungsi Akar

Tentukan invers dari f(x) = √(x + 4), dengan x ≥ -4!

y = √(x + 4)

y² = x + 4

x = y² - 4

f⁻¹(x) = x² - 4, dengan x ≥ 0 ✓

E. Sifat-Sifat Fungsi Invers

Fungsi invers memiliki beberapa sifat penting:

1. Komposisi dengan Fungsi Asal

Fungsi invers dikomposisikan dengan fungsi asalnya menghasilkan fungsi identitas.

(f⁻¹ ∘ f)(x) = x dan (f ∘ f⁻¹)(x) = x

2. Invers dari Invers

Invers dari fungsi invers adalah fungsi asalnya sendiri.

(f⁻¹)⁻¹ = f

3. Domain dan Range Saling Bertukar

Domain fungsi invers adalah range fungsi asal, dan sebaliknya.

D(f⁻¹) = R(f) dan R(f⁻¹) = D(f)

F. Grafik Fungsi dan Inversnya

Grafik fungsi dan inversnya memiliki hubungan geometris yang khas:

Sifat Simetri terhadap Garis y = x

Grafik fungsi invers merupakan pencerminan dari grafik fungsi asal terhadap garis y = x (garis diagonal dengan gradien 1).

  • Jika titik (a, b) terletak pada grafik f, maka titik (b, a) terletak pada grafik f⁻¹.
  • Garis y = x berfungsi sebagai "cermin" yang memantulkan grafik fungsi asal ke grafik fungsi invers.
  • Sifat ini dapat digunakan untuk menggambar grafik fungsi invers tanpa menghitung rumusnya secara eksplisit.

G. Studi Kasus: Penerapan dalam Kehidupan Nyata

Kasus 1: Menghitung Harga Sebelum Diskon

Sebuah toko di koperasi madrasah memberikan diskon 20% untuk semua barang. Jika harga setelah diskon adalah fungsi dari harga awal: f(x) = 0,8x (x = harga awal), maka fungsi inversnya digunakan untuk menghitung harga awal dari harga yang tertera.

Fungsi Invers: f⁻¹(x) = x / 0,8 = 1,25x
Penerapan: Jika harga setelah diskon Rp80.000, maka harga awal = 1,25 × 80.000 = Rp100.000.

Kasus 2: Konversi Suhu Balik

Rumus konversi Celcius ke Fahrenheit: f(C) = 9/5 × C + 32. Fungsi inversnya digunakan untuk mengonversi Fahrenheit kembali ke Celcius.

Fungsi Invers: f⁻¹(F) = 5/9 × (F - 32)
Penerapan: Jika suhu 95°F, maka dalam Celcius = 5/9 × (95 - 32) = 5/9 × 63 = 35°C.

H. Tantangan dan Miskonsepsi Umum

Dalam mempelajari fungsi invers, murid sering mengalami:

  • Kebingungan Notasi: Mengira f⁻¹(x) sama dengan 1/f(x), padahal f⁻¹(x) adalah fungsi invers, bukan kebalikan aljabar.
  • Mengabaikan Syarat Bijektif: Mencoba mencari invers fungsi yang tidak satu-satu (misal: f(x) = x² tanpa pembatasan domain).
  • Kesalahan Aljabar: Salah dalam menyelesaikan persamaan untuk menyatakan x dalam y, terutama pada fungsi pecahan.
  • Lupa Menukar Variabel: Setelah mendapatkan x = ... dalam y, lupa mengganti x dengan f⁻¹(x) dan y dengan x.
  • Mengabaikan Domain Invers: Tidak menyadari bahwa domain fungsi invers adalah range fungsi asal.

J. Perbedaan: Fungsi vs Fungsi Invers

Aspek Fungsi (f) Fungsi Invers (f⁻¹)
Arah Pemetaan Dari domain ke range (x → y) Dari range ke domain (y → x)
Domain Himpunan semua input yang valid Range dari fungsi asal
Range Himpunan semua output yang dihasilkan Domain dari fungsi asal
Grafik Grafik asli Pencerminan grafik asal terhadap y = x
Syarat Keberadaan Selalu terdefinisi Hanya ada jika fungsi asal bijektif
Komposisi (f ∘ f⁻¹)(x) = x (f⁻¹ ∘ f)(x) = x

💡 Poin Penting untuk Ujian

  • ✓ Pahami definisi fungsi invers: f(x) = y ⇔ f⁻¹(y) = x.
  • ✓ Kuasai syarat fungsi memiliki invers: harus bijektif (satu-satu dan pada).
  • ✓ Hafalkan 4 langkah menentukan fungsi invers secara sistematis.
  • ✓ Latihan mencari invers dari berbagai jenis fungsi (linear, pecahan, akar).
  • ✓ Pahami sifat-sifat fungsi invers: komposisi dengan fungsi asal, invers dari invers, pertukaran domain-range.
  • ✓ Ingat hubungan grafik: simetri terhadap garis y = x.
  • ✓ Bedakan notasi f⁻¹(x) (fungsi invers) dengan 1/f(x) (kebalikan aljabar).
  • ✓ Mampu menyelesaikan soal cerita yang memerlukan "pembalikan" proses.
