BAB 2: Fungsi Komposisi

Memahami konsep fungsi komposisi sebagai gabungan dua fungsi atau lebih yang bekerja secara berurutan. Menguasai notasi (f ∘ g)(x), sifat-sifat komposisi, serta aplikasinya dalam pemecahan masalah bertahap.

A. Pengertian dan Hakikat Fungsi Komposisi

Fungsi komposisi adalah penggabungan dua buah fungsi atau lebih secara berurutan, di mana output dari fungsi pertama menjadi input bagi fungsi berikutnya. Konsep ini mirip dengan proses manufaktur bertahap: bahan mentah diproses menjadi barang setengah jadi, lalu diproses lagi menjadi barang jadi.

Secara formal, jika terdapat dua fungsi f dan g, maka fungsi komposisi (f ∘ g) didefinisikan sebagai fungsi yang memetakan x melalui g terlebih dahulu, kemudian hasilnya diproses oleh f.

(f ∘ g)(x) = f(g(x))
Dibaca: "f komposisi g dari x" atau "f bundaran g dari x"

"Fungsi komposisi adalah operasi penggabungan dua fungsi sehingga membentuk fungsi baru, di mana output fungsi pertama menjadi input fungsi kedua."
— Definisi Matematis

B. Notasi dan Alur Komposisi

Untuk memahami fungsi komposisi, murid perlu memahami alur pemetaannya secara bertahap:

1. (f ∘ g)(x)

Fungsi g dikerjakan lebih dulu, hasilnya dimasukkan ke fungsi f.

(f ∘ g)(x) = f(g(x))

2. (g ∘ f)(x)

Fungsi f dikerjakan lebih dulu, hasilnya dimasukkan ke fungsi g.

(g ∘ f)(x) = g(f(x))

Analogi sederhana: Bayangkan mesin konversi mata uang. Mesin pertama (g) mengubah Rupiah → Dollar, lalu mesin kedua (f) mengubah Dollar → Euro. Proses keseluruhan adalah (f ∘ g): Rupiah → Euro.

C. Sifat-Sifat Fungsi Komposisi

Fungsi komposisi memiliki beberapa sifat penting yang harus dikuasai:

1. Tidak Komutatif

Secara umum, (f ∘ g)(x) ≠ (g ∘ f)(x). Urutan komposisi sangat menentukan hasil.

(f ∘ g)(x) ≠ (g ∘ f)(x)

2. Asosiatif

Pengelompokan fungsi tidak mengubah hasil akhir komposisi.

((f ∘ g) ∘ h)(x) = (f ∘ (g ∘ h))(x)

3. Memiliki Fungsi Identitas (I)

Terdapat fungsi identitas I(x) = x yang bersifat netral terhadap komposisi.

(f ∘ I)(x) = (I ∘ f)(x) = f(x)

D. Langkah Menentukan Fungsi Komposisi

Berikut langkah-langkah sistematis untuk menentukan fungsi komposisi:

📘 Contoh Soal:

Diketahui f(x) = 2x + 3 dan g(x) = x². Tentukan (f ∘ g)(x) dan (g ∘ f)(x)!

Penyelesaian (f ∘ g)(x):

(f ∘ g)(x) = f(g(x))

= f(x²)

= 2(x²) + 3

= 2x² + 3 ✓

Penyelesaian (g ∘ f)(x):

(g ∘ f)(x) = g(f(x))

= g(2x + 3)

= (2x + 3)²

= 4x² + 12x + 9 ✓

⚠️ Perhatikan: (f ∘ g)(x) ≠ (g ∘ f)(x), membuktikan fungsi komposisi tidak komutatif.

E. Domain Fungsi Komposisi

Domain fungsi komposisi (f ∘ g) adalah himpunan nilai x yang memenuhi dua syarat:

  • x harus berada dalam domain fungsi g
  • g(x) harus berada dalam domain fungsi f
D(f ∘ g) = { x ∈ Dg | g(x) ∈ Df }

Artinya, domain fungsi komposisi merupakan irisan dari domain kedua fungsi dengan memperhatikan syarat tambahan.

F. Studi Kasus: Penerapan dalam Kehidupan Nyata

Kasus 1: Proses Produksi Kue di Koperasi MAS Diniyah

Koperasi madrasah memproduksi kue dengan dua tahap. Tahap I (fungsi g) mengolah bahan mentah menjadi adonan dengan rumus biaya: g(x) = 5.000x + 20.000 (x = jumlah bahan dalam kg). Tahap II (fungsi f) mengolah adonan menjadi kue jadi dengan rumus: f(x) = 3x + 10.000.

Proses komposisi (f ∘ g)(x):
= f(g(x)) = f(5.000x + 20.000)
= 3(5.000x + 20.000) + 10.000
= 15.000x + 60.000 + 10.000
= 15.000x + 70.000

Jika x = 10 kg bahan, total biaya produksi = 15.000(10) + 70.000 = Rp220.000.

Kasus 2: Konversi Suhu Bertahap

Seorang ilmuwan perlu mengonversi suhu dari Reamur ke Fahrenheit melalui dua tahap: Reamur → Celcius → Fahrenheit.

Tahap 1 (g): R → C, rumus g(R) = 5/4 × R
Tahap 2 (f): C → F, rumus f(C) = 9/5 × C + 32
Komposisi (f ∘ g)(R):
= f(5/4 × R) = 9/5 × (5/4 × R) + 32 = 9/4 × R + 32

G. Tantangan dan Miskonsepsi Umum

Dalam mempelajari fungsi komposisi, murid sering mengalami:

  • Kebingungan Urutan: Mengira (f ∘ g)(x) sama dengan (g ∘ f)(x), padahal tidak komutatif.
  • Kesalahan Substitusi: Salah memasukkan fungsi ke dalam fungsi lain, terutama pada fungsi kuadrat.
  • Mengabaikan Domain: Tidak memeriksa syarat domain fungsi komposisi (misal: penyebut ≠ 0, akar ≥ 0).
  • Kesulitan Membaca Notasi: Bingung membedakan notasi (f ∘ g)(x) dengan (f × g)(x) atau (f + g)(x).

H. Relevansi dalam Konteks MAS Diniyah Limo Jurai

Konsep fungsi komposisi memiliki makna filosofis dalam pendidikan Islam:

  • Proses Berjenjang (Taraqqi): Seperti proses belajar yang bertahap dari dasar ke lanjut (ibtidaiyah → tsanawiyah → aliyyah), fungsi komposisi mencerminkan prinsip kemajuan berkesinambungan.
  • Urutan yang Terjaga (Tertib): Ketidakkomutatifan fungsi komposisi mengajarkan pentingnya menjaga urutan amal dan ibadah sesuai syariat.
  • Aplikasi Hisab: Digunakan dalam perhitungan zakat bertingkat, konversi satuan dalam fikih muamalah, dan penentuan waktu shalat berdasarkan koordinat geografis.

I. Perbedaan: Operasi Fungsi Biasa vs Fungsi Komposisi

Aspek Operasi Aljabar Fungsi (f + g, f × g) Fungsi Komposisi (f ∘ g)
Cara Kerja Kedua fungsi diproses secara paralel pada input yang sama Fungsi diproses secara berurutan (serial)
Notasi (f + g)(x), (f × g)(x) (f ∘ g)(x) = f(g(x))
Sifat Komutatif Komutatif untuk penjumlahan & perkalian Tidak komutatif
Domain Irisan domain kedua fungsi Domain g dengan syarat g(x) ∈ Df
Analogi Dua mesin bekerja bersamaan Dua mesin bekerja berurutan (assembly line)

💡 Poin Penting untuk Ujian

  • ✓ Pahami definisi fungsi komposisi: (f ∘ g)(x) = f(g(x)).
  • ✓ Kuasai tiga sifat utama: tidak komutatif, asosiatif, dan identitas.
  • ✓ Latihan menentukan (f ∘ g)(x) dan (g ∘ f)(x) dari fungsi yang diberikan.
  • ✓ Pahami cara menentukan domain fungsi komposisi dengan syarat irisan.
  • ✓ Mampu menyelesaikan soal cerita dengan menerjemahkan proses bertahap ke dalam notasi komposisi.
  • ✓ Bedakan dengan jelas antara operasi aljabar fungsi dan fungsi komposisi.
